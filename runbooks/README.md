# Runbooks

This directory contains operational runbooks for on-call engineers.

Each runbook follows a consistent structure:

- **Alert / Symptom** — what triggered this runbook
- **Impact** — user-facing and business impact
- **Diagnosis** — step-by-step checks to find the root cause
- **Mitigation** — actions to stop the bleeding
- **Resolution** — how to fully recover
- **Escalation** — who to page and when
